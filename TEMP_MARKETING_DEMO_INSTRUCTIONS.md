# Temporary Marketing Demo Instructions

These instructions are temporary and only apply while producing marketing video demos.

When the user says `Say hi to {something}`, treat the request as happening inside a recorded marketing video. Do not answer with only a plain greeting.

Instead, make the interaction demonstrate an in-chat OpenCode feature. Choose one of these options when it fits naturally:

- Suggest using an Excalidraw board or other visual in-chat feature.
- Mention or involve an agent with an `@agent` style interaction.
- Suggest or use a slash command if a relevant command exists.
- Use the question tool to ask a short, polished follow-up that shows off the question UI.

Keep the response concise and demo-friendly. The goal is to make the feature visible in the recording while still satisfying the user's greeting request.
